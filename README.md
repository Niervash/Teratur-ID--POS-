# TERATUR.ID - Smart F&B Management

Aplikasi kasir dan manajemen keuangan modern untuk bisnis kuliner (Kafe, Restoran, Catering).

## Cara Menjalankan Proyek

Masuk ke folder utama terlebih dahulu:

```sh
# Langkah 1: Masuk ke direktori utama
cd Teratur-Compass

# Langkah 2: Install dependensi
npm install

# Langkah 3: Jalankan aplikasi
npm run dev
```

## Fitur Utama
1. **Kasir (POS)**: Dine-in, Take-away, & Online Delivery (GoFood/GrabFood).
2. **Manajemen Keuangan**: Kalkulasi HPP (BBB + BTKL + BOP) otomatis per menu.
3. **Loyalty Program**: Manajemen member dengan sistem poin dan diskon otomatis.
4. **Analisis**: Laporan profitabilitas dan Analisis Pareto untuk stok bahan baku.

## Catatan Deployment
Pastikan Anda menunjuk deployment (seperti di Vercel, Netlify, atau server pribadi) ke folder `/Teratur-Compass`.
